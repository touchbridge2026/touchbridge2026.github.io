# TouchBridge

Project page for **TouchBridge: Tactile-Conditioned Human-to-Robot Transfer for Dexterous Manipulation**.

Website: https://touchbridge2026.github.io/

The page is a single static `index.html` with assets under `static/`. To preview locally:

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```
